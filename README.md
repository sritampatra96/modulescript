## Memory Optimizer Kit
A zip-ready kit for ChatGPT and Codex: a model + reasoning-effort advisor, an auto-compressing memory, and a staged delivery pipeline that runs on every new task.

- **Download:** [`memory-optimizer-kit.zip`](memory-optimizer-kit.zip) (same content as the [`memory-optimizer-kit/`](memory-optimizer-kit) folder)
- **How to use:** [`START_HERE.md`](memory-optimizer-kit/START_HERE.md)
- **Always on, no pasting per task:** [`DEFAULT_ON.md`](memory-optimizer-kit/DEFAULT_ON.md)
- **Skill:** `task-optimizer` ([`.claude/skills/task-optimizer`](.claude/skills/task-optimizer)), copy into `~/.codex/skills/` or `~/.claude/skills/`
- **Engine:** [`tools/kit.py`](memory-optimizer-kit/tools/kit.py), standard library only
- **Build history:** [`docs/SESSION_LOG.md`](docs/SESSION_LOG.md)

Model names in `memory-optimizer-kit/config/models.json` are examples; edit them to match your account.
